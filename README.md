# Lilyium 🎵

An Android music player client for [Navidrome](https://www.navidrome.org/) — a self-hosted music streaming server.

## What is this?
Lilyium lets you stream your personal music library from a Navidrome server directly on your Android device.

## Features
- Browse and play music from your Navidrome server
- (add whatever features you have here)

## Requirements
- A running Navidrome server
- Android 7.0 (API 24) or higher

## Getting Started
1. Install the APK on your Android device
2. Open the app and enter your Navidrome server URL
3. Login with your Navidrome credentials
4. Enjoy your music!

## Build from Source
1. Clone the repo
```bash
   git clone https://github.com/lily5463/Lilyium.git
```
2. Open in Android Studio
3. Build and run on your device or emulator
